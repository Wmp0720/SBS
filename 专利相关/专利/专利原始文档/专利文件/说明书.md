# 说明书

## 一种基于评测尺度自校准与分阶段裁决的多模型输出对比评测方法及系统

### 技术领域

本发明涉及人工智能和自然语言处理技术领域，尤其涉及一种基于评测尺度自校准与分阶段裁决的多模型输出对比评测方法及系统。

### 背景技术

随着大语言模型（LLM）在智能问答、内容生成、对话交互等场景的规模化应用，多模型间的性能对比评测成为企业优化产品、提升核心竞争力的关键环节。当前行业主流的大模型对比评测方法主要分为三类：人工标注法、固定规则自动评测法、单步裁判模型裁决法。

人工标注法依赖领域专家对模型输出进行质量判定，虽能保证一定准确性，但存在成本高、效率低、主观性强的固有缺陷，不同标注员的判定尺度存在天然差异，难以形成统一且稳定的评测标准；固定规则自动评测法通过预设指标体系进行量化打分，实现了评测流程的自动化，但规则刚性强，无法适应业务场景变化和数据分布偏移，且未考虑模型输出的优势与致命缺陷，易出现评测标准与实际需求脱节的问题；单步裁判模型裁决法直接调用大模型输出"胜/平/负"结论，操作简便但评测过程如同"黑箱"，缺乏中间推理依据，无法追溯结果生成逻辑，且未整合历史标注经验形成结构化知识库，导致评测一致性差。

在实际工程化应用中，上述方法普遍暴露四大核心问题：

一是评测尺度缺乏动态校准能力，不同批次、不同场景下的评测标准易发生漂移，相同质量的模型输出可能得到差异较大的判定结果，导致长期评测数据缺乏可比性；

二是评测流程缺乏逻辑分层设计，未构建思维链递进结构，未整合胜利模式/失败触发器知识库，事实分析与裁决推理耦合，结果异常时无法定位问题根源；

三是裁决过程缺乏结构化事实支撑，直接基于原始输出判定，易受表述风格、语言华丽程度等无关因素干扰，结果的客观性与可解释性不足；

四是人工经验复用性低，标注员识别核心优势与致命缺陷的隐性经验难以转化为显性规则，新标注人员或模型无法有效复用，导致评测标准随人员变动而波动。

这些缺陷严重制约了大模型对比评测的工程化落地与规模化应用，亟需一种兼具高一致性、高可解释性与高复用性的新型评测方法。

### 发明内容

#### 技术问题

本发明要解决的技术问题是：如何提供一种多模型输出对比评测方法及系统，能够实现评测尺度的动态自校准，构建可解释的分阶段裁决流程，并有效复用人工标注经验。

#### 技术方案

为解决上述技术问题，本发明提供一种基于评测尺度自校准与分阶段裁决的多模型输出对比评测方法，包括以下步骤：

**S1、评测尺度自校准步骤：** 基于历史人工精标数据，通过大语言模型结合规则推理算法，自动提取尺度特征并构建双知识库。所述尺度特征包括问题标签与合格率的映射关系、场景化容忍阈值及标注偏好。所述双知识库包括胜利模式知识库和失败触发器知识库。

具体实现中，该步骤包含：
- 精标数据输入层：收集领域专家标注的高质量精标数据，包含用户问题、模型回答、问题标签、合格率（弱智/不合格/合格/优质）、对比裁决结果及标注备注；
- 特征学习层：通过大语言模型结合规则推理算法，自动提取三类核心尺度特征与双知识库特征；
- 输出层：整合上述特征，生成评测尺度约束信息和双知识库。

**S2、单模型结构化标注步骤：** 针对待评测的自研模型与竞品模型，分别加载所述评测尺度约束信息及双知识库，由大语言模型对各模型的回答执行双向识别：
- 核心问题识别：聚焦用户核心需求，从预设标签体系中识别并标注主要问题，优先匹配失败触发器知识库中的致命错误；
- 核心优势识别：从胜利模式知识库中匹配模型输出的核心优势，标注最显著的优势。

输出结构化标注结果，包含"样本ID、用户问题、模型回答、主要问题标签清单、核心优势清单、标注理由"。

**S3、规则映射步骤：** 基于所述结构化标注结果，结合所述评测尺度约束信息与双知识库，自动映射生成严重度等级、优势等级与合格率：
- 严重度等级映射：根据主要问题标签匹配失败触发器知识库的严重性评级，取最高评级作为模型整体严重度等级（1级轻微→5级致命）；
- 优势等级映射：根据核心优势清单匹配胜利模式知识库的影响力评级，取最高评级作为模型整体优势等级（1级微弱→5级显著）；
- 合格率映射：按"严重度等级优先，优势等级补偿"的规则执行。

**S4、双模型对比评估步骤：** 基于两个模型的规则映射结果，结合双知识库，执行客观对比分析：
- 基础指标对比：合格率等级（优质＞合格＞不合格＞弱智）、严重度等级、优势等级；
- 核心特征对比：失败触发器对比（是否命中致命错误、严重性评级差异）和胜利模式对比（核心优势数量、影响力评级总和差异）；
- 主要问题对比：问题类型、数量差异。

**S5、多维度裁决推理步骤：** 仅基于所述双模型对比评估结果与双知识库，按照以下优先级进行最终胜负判定：
- 第一优先级（致命错误裁定）：若任一方严重度等级为5级（致命），直接判该方负；若双方均命中，严重性评级高者负；
- 第二优先级（优势等级裁定）：无致命错误时，优势等级总和高者判胜；若总和一致，高评级优势数量多者胜；
- 第三优先级（合格率裁定）：优势等级一致时，按"优质＞合格＞不合格＞弱智"顺序，合格率更优者判胜；
- 第四优先级（严重度对比）：合格率一致时，严重度等级更低者判胜；
- 第五优先级（问题数量对比）：严重度等级一致时，主要问题标签数量更少者判胜；
- 第六优先级（平局裁定）：上述维度均无法区分时，判为"平"。

输出最终裁决结果（胜/平/负）及裁判说明，说明内容需引用双知识库与对比评估结果，确保可溯源。

本发明还提供一种基于评测尺度自校准与分阶段裁决的多模型输出对比评测系统，包括：
- 评测尺度自校准模块
- 单模型结构化标注模块
- 规则映射模块
- 双模型对比评估模块
- 多维度裁决推理模块
- 知识库动态更新模块（可选）

#### 有益效果

本发明与现有技术相比具有以下有益效果：

1. **评测尺度动态自校准**：基于历史人工精标数据，自动学习评测标准、问题标签与合格率的映射关系、场景化容忍阈值及标注偏好，同步构建胜利模式知识库与失败触发器知识库，将隐性人工经验转化为显性规则，从源头避免尺度漂移，保障跨批次、跨场景评测的一致性。

2. **思维链递进式标注链路**：创新设计"单模型结构化标注→规则映射→双模型对比评估→多维度裁决推理"的分层流程，整合双知识库，各阶段输出明确的结构化数据，形成完整的推理证据链，支持跨环节追溯与人工复检，彻底解决传统单步裁决的"黑箱"问题。

3. **事实与裁决分离机制**：将评测拆分为独立的事实提取（含缺陷与优势）与裁决推理环节，事实提取仅基于双知识库提取模型输出的客观特征并结构化存储，裁决环节仅基于提取的事实进行判定，不访问原始输出，避免表面信息干扰，提升结果客观性与可解释性。

4. **人工经验结构化复用**：通过尺度自校准模块与双知识库，将标注员识别核心优势、致命缺陷的隐性经验转化为显性的约束信息，支持通过新增精标数据定期更新校准标准与知识库，实现人工经验的持续沉淀与规模化复用。

5. **多场景灵活扩展**：核心流程架构不变，通过模块替换与知识库配置调整，可快速适配多模态、医疗/金融等领域垂类、跨语言等场景，拓宽评测适用范围。

### 具体实施方式

下面结合附图和具体实施方式对本发明作进一步详细说明。

#### 实施例一：固定双知识库基础版评测方案

本实施例为核心基础方案，通过固定的胜利模式/失败触发器双知识库与完整的思维链标注链路，实现多模型对比评测的标准化、自动化执行。

**步骤1：双知识库初始化**

基于历史精标数据，预先构建固定的双结构化知识库：

胜利模式知识库示例：
```json
[
  {
    "pattern_name": "结构化呈现",
    "description": "采用清晰的层级结构、列表或表格来组织信息",
    "keywords": ["结构化", "层次", "列表", "表格", "清晰"],
    "impact": "高"
  },
  {
    "pattern_name": "提供增量价值",
    "description": "在回答基础问题之外，提供了额外的有价值信息",
    "keywords": ["额外", "深入", "扩展", "补充", "增值"],
    "impact": "中"
  }
]
```

失败触发器知识库示例：
```json
[
  {
    "trigger_name": "事实性错误",
    "description": "回答中包含与公认事实相悖的错误信息",
    "keywords": ["错误", "不正确", "与事实不符", "过时信息"],
    "severity": "不合格"
  },
  {
    "trigger_name": "核心指令遗忘",
    "description": "未能遵循用户明确提出的核心约束",
    "keywords": ["未遵循", "未执行", "遗忘", "忽略"],
    "severity": "不合格"
  }
]
```

**步骤2：评测尺度约束信息配置**

基于精标数据提炼固定的评测尺度规则，包含三类核心内容：
- 标签-合格率映射表：明确问题标签与合格率的对应关系；
- 场景化容忍阈值规则：区分核心场景与非核心场景的问题容忍度；
- 边界样本判定准则：明确临界样本的判定逻辑。

**步骤3：思维链标注链路执行**

按四阶段流程执行完整评测：

（1）单模型结构化标注：大语言模型加载双知识库与尺度规则，接收"用户问题+模型回答"，识别1-3个主要问题与1-2个核心优势，输出结构化标注结果；

（2）规则映射：基于标注结果，自动映射生成严重度等级、优势等级与合格率；

（3）双模型对比评估：从基础指标与核心特征维度对比，生成结构化对比结果；

（4）多维度裁决推理：按"致命错误→优势等级→合格率→严重度→问题数量→平局"的优先级判定胜负。

**步骤4：结果输出与存储**

将全流程结构化结果存储至Excel文件，支持按样本ID跨环节追溯。

本实施例的有益效果：
- 部署成本低：双知识库与尺度规则固定，无需持续投入精标数据更新；
- 执行效率高：省去动态学习过程，单样本处理时间≤3秒；
- 结果一致性强：固定规则与知识库避免了动态调整带来的波动，跨批次评测一致性≥92%。

#### 实施例二：动态更新双知识库优化版评测方案

本实施例在基础版之上，增加双知识库与评测尺度的动态更新机制，适用于场景需求迭代快、新问题/新优势频繁出现的评测场景。

**步骤1：初始知识库与尺度规则构建**

同实施例一的步骤1-2，完成固定双知识库与初始评测尺度约束信息的搭建。

**步骤2：新增精标数据收集与融合**

定期收集新增高质量精标数据（例如每周期≥500条，标注一致性≥90%），将新增数据与历史数据合并，剔除重复样本。

**步骤3：双知识库动态更新**

通过大语言模型自动学习新增数据特征，更新双知识库：
- 胜利模式知识库更新：识别新增高频优势（出现频次≥30次），补充至知识库；
- 失败触发器知识库更新：识别新增高频致命错误（出现频次≥30次），补充至知识库；
- 去重优化：删除知识库中低频优势/错误（新增数据中出现频次＜5次）。

**步骤4：评测尺度约束信息迭代**

基于融合后的全量数据，重新提炼评测尺度规则。

**步骤5：思维链标注链路执行**

同实施例一的步骤3-4，基于更新后的双知识库与尺度规则执行评测。

本实施例的有益效果：
- 适配性更强：动态更新机制使知识库与尺度规则紧跟场景迭代；
- 评测精度更高：融合新增精标数据，规则与知识库更贴合实际评测需求；
- 扩展性更优：无需重构核心流程，仅通过数据更新即可适配新场景；
- 经验沉淀更充分：自动吸收新增标注经验，实现人工知识的持续复用。

#### 扩展应用场景

本发明的技术方案可灵活扩展至以下场景：
- 多模态大模型评测：将单模型结构化标注环节扩展至图文、音视频内容的事实提取；
- 领域垂类模型评测：针对医疗、金融、教育等专业领域，通过领域专属精标数据进行尺度自校准；
- Agent行为路径评测：将模型输出替换为Agent的行为路径描述，通过事实归档环节记录行为步骤的合理性与有效性；
- 跨语言模型评测：新增语言适配层，将不同语言的模型输出转化为统一语义表示后执行评测。
